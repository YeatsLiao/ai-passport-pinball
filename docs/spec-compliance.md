# 规格对照表：原版 Space Cadet vs 当前实现

对照基准：[`space-cadet-spec.md`](./space-cadet-spec.md)（规格，条目号 §x.y）。
差距来源：[`gap-list.md`](./gap-list.md)（差距清单，条目号 A/B/C/D）。
被对照代码：`main/pb_game.c`、`main/pb_game.h`、`main/pb_table.c/.h`、`main/pb_render.c`、
`tools/pb_art.py`。

状态含义：

- **一致** —— 本轮之前就已与规格相符，未改动。
- **已修复** —— 本轮按差距清单改动，已通过编译与预览图核对。
- **待上板** —— 逻辑与静态检查已确认，手感/可读性需实机复核（见文末 D 组）。
- **不移植** —— 规格 §6 明确排除，代码中不得出现其变体。
